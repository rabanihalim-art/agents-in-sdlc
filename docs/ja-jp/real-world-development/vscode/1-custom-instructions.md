リポジトリ命令とパス単位の instruction file を使って、Copilot にプロジェクトの規約を伝えます。

1. `.github/copilot-instructions.md` と `.github/instructions/` を確認します。
2. 現在の命令で publishers helper の生成を依頼します。
3. リポジトリ全体の標準として TSDoc とファイルヘッダーの規則を追加します。
4. 同じプロンプトを再実行し、結果をレビューします。

> [!CAUTION]
> Copilot の生成結果は確率的に変化します。要件と規約への適合を確認してください。
