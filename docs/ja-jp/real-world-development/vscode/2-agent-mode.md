VS Code の Copilot Chat エージェント モードで、バックログの issue からフィルタリング機能を実装します。

1. **Chat** ビューを開き、**Agent** モードを選択します。
2. リポジトリのフィルタリング issue をコンテキストに追加します。
3. 実装計画、コード、テストをレビューしてから適用します。
4. テストを実行し、変更を手動で確認します。
