Model Context Protocol (MCP) サーバーを Copilot Chat に追加し、外部ツールを使って機能を確認します。

1. MCP の設定を開きます。
2. 信頼できる MCP サーバーだけを登録します。
3. Playwright MCP を使って実行中のサイトを確認します。
4. 結果を issue の受け入れ条件と比較します。

> [!CAUTION]
> MCP サーバーには、他の依存関係と同じようにセキュリティ上の影響があります。提供元と権限を確認してください。
