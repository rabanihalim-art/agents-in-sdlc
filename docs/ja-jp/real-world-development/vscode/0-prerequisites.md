VS Code の演習を始める前に、Tailspin Toys のコピー、作業用 codespace、GitHub Copilot Chat を準備します。

1. [Tailspin Toys template][template-repository] を開き、**Use this template**、**Create a new repository** の順に選択します。
2. リポジトリで **Code**、**Codespaces**、**+** の順に選択します。
3. codespace で **Copilot Chat** を開き、必要なら GitHub にサインインします。

> [!NOTE]
> codespace の代わりにローカルの [dev container][dev-containers] も使用できます。

[template-repository]: https://github.com/github-samples/tailspin-toys
[dev-containers]: https://code.visualstudio.com/docs/devcontainers/containers
