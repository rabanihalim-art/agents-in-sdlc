エージェントが開いたプルリクエストをレビューし、チェック結果に基づいて反復します。

1. 変更されたファイルとテストを確認します。
2. 必須チェックの結果を確認します。
3. 修正が必要な場合は、具体的なレビューコメントを送ります。
4. 更新された差分を再確認します。
5. 要件を満たしたらプルリクエストをマージします。

## まとめ

cloud agent に作業を委任し、監視、指示、レビューを行う一連の流れを完了しました。
