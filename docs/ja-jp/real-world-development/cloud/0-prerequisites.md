Copilot cloud agent の演習を始める前に、Tailspin Toys リポジトリのコピーと、それを編集するための [codespace][codespaces] を作成します。

## リポジトリを準備する

1. [Tailspin Toys template][tailspin-template] を開きます。
2. **Use this template**、**Create a new repository** の順に選択します。
3. イベントに参加している場合はメンターの指示に従い、それ以外の場合は Copilot にアクセスできる組織を選びます。
4. 作成した `organization-or-user-name/repository-name` を記録します。

## codespace を作成する

1. 作成したリポジトリに移動します。
2. **Code**、**Codespaces**、**+** の順に選択します。
3. codespace の作成が完了するまで待ちます。

> [!NOTE]
> このワークショップは codespace またはローカルの [dev container][dev-containers] で実行できます。
