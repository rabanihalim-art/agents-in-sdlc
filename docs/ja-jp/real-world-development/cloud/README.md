**[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** は、クラウドで非同期に動作します。GitHub で作業を割り当てると、リポジトリを調査して変更を作成し、プルリクエストを開きます。

このワークショップでは、カスタム命令を追加し、issue を割り当て、カスタムエージェントで作業方法を調整し、セッションを監視して、プルリクエストをレビューします。

| [0. 前提条件][ex0] | セットアップ | リポジトリと codespace を作成します |

## 前提条件

- [ ] GitHub Copilot Student、Pro、Pro+、Business、Enterprise のいずれかの有効なプラン
- [ ] アカウントまたは組織で cloud agent が有効
