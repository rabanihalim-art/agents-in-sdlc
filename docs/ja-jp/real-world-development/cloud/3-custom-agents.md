カスタムエージェントを使うと、特定の専門知識やレビュー手順を再利用できます。

1. `.github/agents/` のエージェント定義を確認します。
2. `name` と `description` の frontmatter を確認します。
3. issue またはプルリクエストで、そのエージェントに適した作業を割り当てます。
4. 結果をレビューし、必要なら追加の指示を送ります。
