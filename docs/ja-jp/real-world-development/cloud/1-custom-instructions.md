cloud agent がプロジェクトの規約に従えるよう、リポジトリのカスタム命令を追加します。

## シナリオ

Tailspin Toys の命名、テスト、アクセシビリティの規約を `.github/copilot-instructions.md` に記述します。エージェントは issue を実装するときに、このファイルをコンテキストとして読み取ります。

## 手順

1. codespace でリポジトリを開きます。
2. `.github/copilot-instructions.md` を作成または更新します。
3. プロジェクトの構造、テスト、UI の要件を明確に記述します。
4. 変更をコミットしてプッシュします。
