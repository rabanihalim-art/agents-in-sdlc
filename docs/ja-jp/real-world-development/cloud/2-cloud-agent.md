GitHub issue を Copilot cloud agent に割り当て、非同期に実装させます。

## 手順

1. Tailspin Toys リポジトリの **Issues** を開きます。
2. 対応する issue を選択します。
3. **Assign to Copilot** を選択します。
4. 追加の指示を確認してタスクを送信します。
5. エージェントが作成したブランチとプルリクエストを確認します。

> [!NOTE]
> エージェントの作業中も、ローカルの開発を続けられます。
