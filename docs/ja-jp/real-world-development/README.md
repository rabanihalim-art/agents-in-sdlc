現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を体験します。変更を計画し、コードを作成し、動作をテストし、プルリクエストをレビューし、エージェントで作業を管理します。

## シナリオ

架空の会社 Tailspin Toys の新しい開発者として、ボードゲームのクラウドファンディングサービスを開発します。チームのバックログは GitHub issue として用意されています。

## 作業環境を選ぶ

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。

### [GitHub Copilot app][app]

デスクトップアプリで並列セッションを実行し、キャンバスと issue を扱います。

### [GitHub Copilot cloud agent][cloud]

GitHub issue を非同期エージェントに割り当て、進捗とプルリクエストを確認します。

### [Visual Studio Code][vscode]

エディターを離れずに Copilot Chat、MCP サーバー、カスタムエージェントを使います。
