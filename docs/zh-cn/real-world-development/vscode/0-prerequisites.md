创建 Tailspin Toys 存储库副本，启动 [codespace][codespaces]，并确认 Visual Studio Code 中的 GitHub Copilot Chat 可用。

1. 打开 [Tailspin Toys 模板][tailspin-template]，选择 **Use this template** 创建存储库。
2. 打开存储库的 **Code** 菜单，进入 **Codespaces**，选择 **+**。
3. 在 VS Code 中打开 Copilot Chat，并按提示登录。

![选择 Code 按钮](../../../_images/ex0-code-button.png)

> [!NOTE]
> 本研讨会可在 codespace 或本地 [dev container][dev-containers] 中运行。
