使用 Copilot 智能体模式为 Tailspin Toys 添加按类别和发行商筛选的功能。智能体会探索项目、修改数据层和界面、运行测试并修复发现的问题。

## 工作步骤

先运行网站并查看当前功能，然后让 Copilot 根据待办事项实现筛选。选择 **Agent** 模式，添加 UI 指令上下文，审查生成的代码和测试，确认功能后选择 **Keep**。

> [!CAUTION]
> Copilot 具有概率性。始终审查 AI 生成的代码，并在合并前运行测试。
