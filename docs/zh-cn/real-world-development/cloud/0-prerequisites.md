开始云智能体练习前，先创建 Tailspin Toys 存储库副本并启动一个 [codespace][codespaces]，用于编辑指令文件和审查云智能体生成的工作。

## 设置实验存储库

打开 [Tailspin Toys 模板][tailspin-template]，选择 **Use this template**，再选择 **Create a new repository**。记下创建的存储库路径。

![使用此模板按钮](../../../_images/ex0-use-template.png)

## 创建 codespace

打开新建的存储库，选择绿色的 **Code** 按钮，打开 **Codespaces** 选项卡，然后选择 **+** 创建 codespace。

![选择 Code 按钮](../../../_images/ex0-code-button.png)

> [!NOTE]
> 本研讨会可在 codespace 或本地 [dev container][dev-containers] 中运行。

## 总结和下一步

你已创建实验存储库并开始创建 codespace。接下来，继续学习 [练习 1：自定义指令][next-lesson]。
