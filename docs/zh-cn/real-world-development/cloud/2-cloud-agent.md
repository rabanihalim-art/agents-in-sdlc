GitHub Copilot 云智能体可以异步执行更新代码和添加功能等任务，并创建供人工审查的草稿 PR。

## 场景

Tailspin Toys 需要补充代码文档，并在游戏详情页显示相关游戏。这些范围明确的任务适合分配给云智能体。

## 分配议题

在 GitHub 上创建议题，填写清晰的标题和要求，然后选择 **Assign to Copilot**。监控生成的 PR 和会话，检查待办事项及执行计划。

## 总结和下一步

本练习介绍了如何配置环境、编写范围明确的议题并将工作分配给云智能体。下一步是学习[自定义智能体][next-lesson]。
