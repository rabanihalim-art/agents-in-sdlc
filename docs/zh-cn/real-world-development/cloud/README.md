**[GitHub Copilot 云智能体](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** 可以在云端异步工作。将工作分配到 GitHub 后，云智能体会在后台探索存储库、进行更改并创建拉取请求。

这些练习将介绍云智能体指令、自定义智能体、会话监控和拉取请求迭代。

## 练习

| 练习 | 主题 | 说明 |
|----------|-------|-------------|
| [0. 先决条件][ex0] | 设置 | 创建存储库和 codespace |
| [1. 自定义指令][ex1] | 上下文 | 添加云智能体遵循的自定义指令 |
| [2. 云智能体][ex2] | 异步智能体 | 将议题分配给 Copilot 云智能体 |
| [3. 自定义智能体][ex3] | 专用智能体 | 审查和使用自定义智能体 |
| [4. 管理智能体][ex4] | 监控 | 监控并指导智能体会话 |
| [5. 迭代][ex5] | 审查 | 审查 PR、迭代 Copilot 的工作并选择下一步 |

## 先决条件

参加本研讨会前，请确保拥有 GitHub 账户和已启用的 **Copilot Student、Pro、Pro+、Business 或 Enterprise** 计划，并且账户或组织已启用 Copilot 云智能体。

> [!NOTE]
> 云智能体适用于除 Copilot Free 之外的所有上述计划。Copilot Business 或 Enterprise 需要管理员为组织启用该功能。
