## 安全性和 GitHub Copilot 云智能体

云智能体在隔离环境中异步运行。存储库权限、GitHub Actions 工作流审批和外部资源访问限制共同保护工作过程。

## 审查并迭代

在 **Pull Requests** 中打开生成的 PR，选择 **Files changed** 查看代码。通过提及 **@copilot** 的评论请求补充文档、测试或可访问性改进，然后再次审查提交。

## 总结和下一步

你已完成云智能体研讨会：配置指令、分配议题、使用自定义智能体、监控会话，并审查和迭代拉取请求。
