自定义智能体是针对特定任务或领域的专用 AI 助手。它们由 `.github/agents` 中的 Markdown 文件定义，可以编码团队的可访问性、安全性和测试实践。

## 场景

Tailspin Toys 希望提高深色主题的对比度。你将使用可访问性智能体生成可切换的高对比度模式。

## 查看并分配自定义智能体

打开 `.github/agents/accessibility.md`，查看其 `name` 和 `description` 前置内容以及可访问性职责。然后创建议题并将其分配给 **Accessibility agent**。
