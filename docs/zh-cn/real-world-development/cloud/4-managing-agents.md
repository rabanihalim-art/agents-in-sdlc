使用 [Copilot agents 页面](https://github.com/copilot/agents) 查看云智能体任务、执行步骤和相关拉取请求。

## 指导云智能体

打开正在运行的会话，在 **Steer active session while Copilot is working** 对话框中请求同时添加浅色模式，然后按 <kbd>Enter</kbd> 发送。Copilot 会在当前步骤完成后将请求加入工作流。
