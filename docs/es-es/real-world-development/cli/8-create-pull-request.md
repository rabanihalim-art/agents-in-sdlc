Revisa conjuntamente el trabajo de filtrado y sus comprobaciones de calidad. Confirma los cambios, crea una solicitud de incorporación de cambios y usa Agent Merge para combinarla cuando todo esté listo.

## Revisión final

Inspecciona el diff, ejecuta las pruebas y verifica la funcionalidad en el navegador. Comprueba también las instrucciones personalizadas, la habilidad de comprobación de calidad y el agente de QA.

## Crear y combinar la solicitud

Pide a Copilot CLI que cree la solicitud, revisa sus comprobaciones y autoriza la combinación solo después de que pasen las validaciones requeridas.
