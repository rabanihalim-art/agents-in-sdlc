Asigna una incidencia preparada al agente de GitHub Copilot en la nube. El agente explorará el repositorio, implementará el cambio y abrirá una solicitud de incorporación de cambios.

## Supervisar el trabajo

Revisa el plan, los cambios y las comprobaciones. Usa los comentarios de la solicitud para pedir correcciones cuando sea necesario.

## Revisar la solicitud

Confirma que el resultado cumple la incidencia antes de combinarlo.
