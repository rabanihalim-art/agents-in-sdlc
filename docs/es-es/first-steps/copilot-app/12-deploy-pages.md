Da un hogar público a Space Quiz mediante GitHub Pages. Copilot puede preparar el flujo de trabajo y guiar la publicación, pero debes revisar los cambios y confirmar que el sitio está disponible.

## Escenario

Space Quiz ya está en un repositorio de GitHub, pero necesita una forma sencilla de probarlo. Publicar el sitio con GitHub Pages lo hace accesible desde una URL pública sin añadir un servidor.

## Preparar y revisar la publicación

En la sesión de la aplicación Copilot para `space-quiz`, pide que prepare un flujo de trabajo de GitHub Pages, cree una solicitud de incorporación de cambios y espere a tu revisión. Revisa los permisos, los pasos de compilación y el origen de la publicación antes de autorizar la combinación.

## Verificar la publicación

Sigue la ejecución de GitHub Actions hasta que termine correctamente. Abre la URL comunicada y confirma que Space Quiz se carga.
