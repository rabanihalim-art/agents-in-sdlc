Publique o aplicativo no GitHub Pages e confirme que ele está disponível na web.

## Publicar o aplicativo

Use o Copilot para configurar a publicação e siga as instruções exibidas para executar o workflow do GitHub Actions.

## Verificar a publicação

Quando o workflow terminar, abra a URL publicada e confirme que o aplicativo funciona no navegador.
