Use os modos Plan e Autopilot do Copilot CLI para planejar e implementar uma funcionalidade de filtragem.

## Planejar antes de editar

Use `/plan` para analisar a issue, considerar o trabalho existente e criar um plano de implementação. Revise o plano antes de iniciar a implementação.

## Implementar a funcionalidade

Escolha o modo apropriado, acompanhe as alterações e execute as verificações relevantes antes de revisar o resultado.
