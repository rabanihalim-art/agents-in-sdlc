O agente de nuvem do GitHub Copilot permite trabalhar de forma assíncrona na nuvem. Atribua tarefas no GitHub para que o agente explore o repositório, faça alterações e abra um pull request enquanto você realiza outras atividades.

## Exercícios

| Exercício | Tema | Descrição |
|-----------|------|-----------|
| [0. Pré-requisitos][ex0] | Configuração | Crie seu repositório e codespace |
| [1. Instruções personalizadas][ex1] | Contexto | Adicione instruções personalizadas |
| [2. Agente de nuvem][ex2] | Agente assíncrono | Atribua issues ao agente de nuvem |
| [3. Agentes personalizados][ex3] | Agentes especializados | Explore agentes personalizados |
| [4. Gerenciar agentes][ex4] | Monitoramento | Monitore e oriente sessões |
| [5. Iterar][ex5] | Revisão | Revise pull requests e itere sobre o trabalho |

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano **Copilot Student, Pro, Pro+, Business ou Enterprise** ativo
- [ ] O agente de nuvem do Copilot habilitado para sua conta ou organização
